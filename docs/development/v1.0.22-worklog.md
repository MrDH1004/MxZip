# MxZip v1.0.22 작업 내역 (2026-11-01)

브랜치: `feat/native-performance` → `main` 병합 완료. 두 브랜치 모두 `e280a47`.

## 1. 종료 시 크래시 수정 (`8a204ce`)
- 원인: `ExitProcess` → DLL_PROCESS_DETACH → shiboken6 `BindingManager::~BindingManager` → `Object::destroy` → `releaseWrapper`에서 널 포인터 접근.
- 수정: `appcore.hard_exit()`가 stdio flush 후 `TerminateProcess`로 종료. `yzip_main.py`, `yzip_gui.finish`/`__main__`는 예외를 잡아 기록한 뒤 `hard_exit`로 나간다.
- 검증: 수정 전 80회 중 5회 크래시 → 수정 후 단독 120회, 동시 60라운드 모두 0회. `exe_verbs_smoke` 57/57 ×3.
- 테스트: `test_hard_exit.py` (FLS 콜백 프로브로 정상 종료 경로를 타지 않는지 확인).

## 2. 7z 헤더 직접 읽기
- `sevenzip_header.py` 신규: 7zFormat 명세대로 헤더를 읽어 py7zr import(~0.13 s)를 피한다. 지원하지 않는 코더는 `Unsupported` → py7zr로 넘어간다.
- 압축 시 헤더를 LZMA2 인코딩 헤더(kEncodedHeader)로 쓰고, 압축이 안 되는 데이터는 LZMA2 비압축 청크로 저장.
- 테스트: `test_sevenzip_header.py`.

## 3. 제품명 MxZip 변경 / 아이콘 (`8598034`, `9c1ff21`)
- 화면 문자열, 설치 프로그램(AppName MxZip, 게시자 YMX), 셸 메뉴, 버전 정보, README 변경.
- 업데이트 호환을 위해 내부 이름(`yzip.exe`, 설치 폴더, 레지스트리 키)은 유지.
- 아이콘: YMX 로고 색 + 지퍼, 흰 타일(시안 E). `make_icon.py`, 시안 생성용 `make_icon_concepts.py`.

## 4. 성능 개선 (`2dc42ae`, `d2aa14f`)
- 시작 비용: 지연 import(`_LazyModule`), dataclass 대신 일반 클래스, argparse 없는 빠른 인자 파서.
- 스레드 풀: threading 기반 경량 풀, 남은 작업이 5 ms 미만이면 인라인 실행.
- 압축 해제: 폴더별 realpath 캐시(`TargetResolver`), 새 파일은 `"xb"`로 바로 쓰기, 열린 핸들에 `SetFileTime`, 16 MB 이상 ZIP 항목은 write-behind.
- 시도 후 되돌림: 256 KB 7z 블록(압축 파일 37% 커짐).
- 타사 압축 프로그램 대비(교대 측정 7회, 중앙값, 기하평균):

| | 개선 전 | 개선 후 |
|---|---|---|
| 압축 | 63% | 110% |
| 압축 해제 | 36% | 75% |
| 전체 | 48% | 91% |

- 한계: 작은 작업의 압축 해제는 Python 시작 비용(~0.06 s) 때문에 30~50% 수준.

## 7. 타사 제품명 제거 (`c573ce5`)
- 저장소 파일 38개에서 특정 제품명을 "타사 압축 프로그램"으로 바꿈. 성능 문서는 `docs/performance/third-party-parity-2026-11.md`로 이름 변경.
- 저장소에 타사 실행 파일 경로를 두지 않도록, 호환 테스트와 벤치마크는 환경변수 `YZIP_REF_ARCHIVER`에 그 경로를 넣어야 실행된다. 설정하지 않으면 해당 테스트는 건너뛴다.
